Учебный веб-сайт для поиска и покупки стоковых изображений, шаблонов и 3D-ресурсов.

## 📋 Возможности

- 🏠 Главная страница с популярными категориями фото
- 🔐 Страница входа в аккаунт
- 💳 Страница оформления подписки
- 🖼️ Карточка отдельного изображения с описанием лицензии
- ✉️ Формы обратной связи и предложений
- 📱 Адаптивная вёрстка

## 🛠️ Стек технологий

| Слой | Технологии |
|------|-----------|
| Frontend | HTML5, CSS3, JavaScript (Fetch API) |
| Backend | PHP 7.4+, PDO |
| База данных | MySQL 5.7+ |

## 🚀 Быстрый старт

### Требования

- PHP 7.4 или выше
- MySQL 5.7 или выше
- Веб-сервер (Apache / Nginx) или сборка XAMPP / OpenServer / MAMP
