# Arfenon — Стоковые фото

Учебный веб-сайт для поиска и покупки стоковых изображений, шаблонов и 3D-ресурсов.

## Описание
Проект реализует клиент-серверную архитектуру: фронтенд на чистом HTML/CSS/JS и бэкенд на PHP, который взаимодействует с базой данных MySQL для сохранения пользовательских данных, отзывов и предложений.

## Стек технологий
* **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
* **Backend:** PHP 7.4+
* **База данных:** MySQL 5.7+

## Функционал
* Главная страница с популярными категориями фото
* Страница входа в аккаунт
* Страница оформления подписки
* Карточка отдельного изображения с описанием лицензии
* Формы обратной связи и предложений (сохранение данных в БД)

## Установка и запуск

### Требования
* PHP 7.4 или выше
* MySQL 5.7 или выше
* Локальный веб-сервер (Apache / Nginx) или сборки XAMPP / OpenServer / MAMP
